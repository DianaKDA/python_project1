# Мини-маркетплейс

## Описание

Данный проект представляет собой упрощённую версию мини-маркетплейса, где покупатели могут просматривать товары, добавлять их в корзину и оформлять покупки, а продавцы могут добавлять, редактировать и удалять свои товары.

## Функционал

### Покупатели (Buyer):
- Регистрация/вход в систему.
- Просмотр всех доступных товаров.
- Добавление товара в корзину.
- Просмотр корзины.
- Оформление покупок.

### Продавцы (Seller):
- Регистрация/вход в систему.
- Добавление товара.
- Редактирование товара.
- Удаление товара.
- Просмотр своих товаров.

## Требования

- Python 3.7+
- Файл данных `users.json` для хранения информации о пользователях.
- Файл данных `products.json` для хранения информации о товарах.

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш_репозиторий/mini-marketplace.git
   ```

2. Перейдите в папку проекта:
   ```bash
   cd mini-marketplace
   ```

3. Создайте файлы данных:
   - `users.json`:
     ```json
     []
     ```
   - `products.json`:
     ```json
     []
     ```

4. Запустите проект:
   ```bash
   python marketplace.py
   ```

## Пример использования

1. Вход в систему или регистрация нового пользователя.
2. Для покупателя:
   - Просмотр всех товаров.
   - Добавление товаров в корзину.
   - Просмотр корзины.
   - Оформление покупки.
3. Для продавца:
   - Добавление нового товара.
   - Редактирование существующего товара.
   - Удаление товара.
   - Просмотр своих товаров.
